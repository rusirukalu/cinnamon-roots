# Ceylon Cinnamon Roots

> **"An authentic Ceylon cinnamon experience, rooted in Sri Lankan heritage."**

A premium editorial digital experience and booking application for **Ceylon Cinnamon Roots**, an exclusive cinnamon plantation and cultural immersion journey in Sri Lanka.

---

## Overview

Ceylon Cinnamon Roots invites international travelers to discover the craft, culture, and craftsmanship behind authentic Ceylon cinnamon through a 120-minute guided plantation experience (*Plantation to Quill*).

### Key Features
* **12 Editorial Sections:** Seamless storytelling covering Welcome, Heritage, 5-Stage Craft Journey, Plantation, Refreshments, and FAQ.
* **Interactive Booking Enquiry Generator:** Validates preferred dates against Sri Lanka local time (`Asia/Colombo`), accommodates 1–10 guests, and generates a structured enquiry for instant clipboard copying or `.txt` download.
* **Accessible Gallery Lightbox:** Full-screen photography viewer with keyboard navigation (`ArrowLeft` / `ArrowRight` / `Escape`) and Unsplash attributions.
* **AEO & SEO Optimized:** Integrated Schema.org structured data (`Organization`, `TouristAttraction`, `FAQPage`), dynamic XML sitemap, and explicit allow rules for AI search agents (`GPTBot`, `PerplexityBot`, `ClaudeBot`, `Google-Extended`).
* **High-Performance Assets:** Fully responsive multi-resolution picture elements (`.avif` and `.webp` sets) with preloaded web fonts (`Instrument Serif` & `Manrope`).

## Getting Started

### Prerequisites
* **Node.js:** v20+ (v26+ recommended)
* **npm:** v10+

### Installation
```bash
git clone https://github.com/rusirukalu/ceylon-cinnamon-roots.git
cd ceylon-cinnamon-roots
npm install
```

### Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view the live application.

### Running Tests
```bash
npm run test
```

### Production Build
```bash
npm run build
npm run start
```
